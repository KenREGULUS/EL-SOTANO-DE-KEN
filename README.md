## 📖 ¿Qué es esto?

**El Sótano de KEN REGULUS** es mi página web con estilo pixel art donde reúno recursos de Minecraft para descargar gratis: texturas, addons, mods y shaders, tanto para **Bedrock** como para **Java**.

👉 **Web:** https://kenregulus.github.io/EL-SOTANO-DE-KEN/

---

## 📦 ¿Qué puedes encontrar?

| Apartado | Para qué versión |
|----------|------------------|
| 🎨 **Texturas** | Bedrock y Java |
| 🧩 **Addons** | Bedrock |
| 🔧 **Mods** | Java |
| ✨ **Shaders** | Bedrock y Java |

---

## ⚙️ Cómo descargar

1. Entra a la web y elige tu versión de Minecraft y el apartado que quieres.
2. Busca el archivo que te interesa y toca el botón **ENLACE**.
3. Copia el link, pégalo en Google y descarga. ¡Listo!
